KTIR RKHIS STORE
================

This is a complete static e-commerce catalog website.

Included now:
- 18 products already provided in the chat
- Arabic / English language switch
- Search by product name or code
- Product categories
- Add to Bag
- Quantity controls and total
- Checkout form: customer name, phone, area, address and notes
- WhatsApp order generation
- Mobile-friendly responsive design
- Cart saved in the browser

WHATSAPP CHECKOUT
-----------------
The store WhatsApp checkout is configured for +961 76 861 904.
Customers can send their completed order directly to this number.

HOW TO OPEN IT
--------------
Double-click index.html.

HOW TO PUT IT ONLINE
--------------------
Upload the whole "ktir-rkhis-store" folder to any static host such as Vercel,
Netlify, GitHub Pages, or your web hosting account.

PRODUCTS
--------
Product information is stored in products.js.
Product images are stored in assets/ using their product code as the filename.

Future products can be added by:
1. Adding the product image to assets/
2. Adding one new product object to products.js

Files:
- index.html
- styles.css
- app.js
- products.js
- config.js
- assets/
